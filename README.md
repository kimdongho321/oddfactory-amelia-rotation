# 아멜리아 화면 회전

트릭컬 아멜리아가 폰 화면 위에 나와 지내는 Android 앱입니다. 세로 화면엔 아멜리아, 가로 화면엔 R41 아멜리아가 나와요.

- 두 번 터치: 차원문에 빨려 들어간 뒤 가로·세로 전환 → 반대 아멜리아 등장
- 세 번 터치: 메뉴(설정·회전 원래대로·종료)
- 블루투스 기기(버즈 등)를 연결하면: 차원 배송 드론 모션
- 길게 누르고 있기: 볼 꼬집혀 버둥 → 놓으면 넘어졌다 일어나요
- 누른 채 끌기: 위치 옮기기

필요한 권한: 다른 앱 위에 표시, 시스템 설정 변경(가로·세로 전환), 알림, 근처 기기(블루투스 연결 감지).

설치: [Releases](../../releases/latest)에서 `oddfactory-amelia-rotation-vc<번호>-sdk26.apk`를 받아 설치하세요. 앱 설정 화면의 '업데이트 확인'으로 새 버전을 받을 수 있어요.

트릭컬 팬아트로 만든 비공식·비상업 팬메이드 앱이에요. 원작 캐릭터와 게임에 대한 권리는 원저작권자에게 있어요.
